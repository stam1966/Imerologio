# Πρόγραμμα Δράσεων Σχολείου

Εφαρμογή για Windows για τον προγραμματισμό και την παρακολούθηση των δράσεων του σχολείου, με Οδηγό Ημερών & Επετείων, Ημερολόγιο Σχολικής Ζωής, εκτυπώσεις και εξαγωγές για ιστοσελίδα, Google Calendar και ICS. Λειτουργεί τοπικά στον υπολογιστή, χωρίς Internet· τα δεδομένα του σχολείου δεν φεύγουν ποτέ από αυτόν.

## Λήψη

**[⬇ Λήψη της τελευταίας έκδοσης (Setup.exe)](https://github.com/stam1966/Imerologio/releases/latest/download/Programma_Draseon_Setup.exe)** και ανοίξτε το αρχείο (Windows 64-bit και 32-bit). Δεν χρειάζονται δικαιώματα διαχειριστή. Αν τα Windows δείξουν «Τα Windows προστάτευσαν τον υπολογιστή σας», πατήστε «Περισσότερες πληροφορίες» → «Εκτέλεση οπωσδήποτε».

Όλες οι εκδόσεις και η φορητή έκδοση (USB / κοινόχρηστος φάκελος): [Releases](https://github.com/stam1966/Imerologio/releases).

**Από την παλιά έκδοση (v1.x):** στην πρώτη εκκίνηση επιλέξτε «Μεταφορά δεδομένων από την παλιά έκδοση» και το αρχείο `school_actions.db` (φάκελος `data` ή `Shared\data`). Όλα μεταφέρονται αυτούσια.

## Τι κάνει

- Δράσεις: καταχώριση, αναζήτηση (χωρίς τόνους/κεφαλαία), φίλτρα ανά σχολικό έτος, κατηγορία, κατάσταση και Calendar, μαζικές ενέργειες, προβολή λίστας ή μήνα.
- Οδηγός Ημερών & Επετείων: θεσμοθετημένες ημέρες, επέτειοι, ορόσημα εσωτερικής αξιολόγησης· δημιουργία δράσεων με ένα κλικ.
- Ημερολόγιο Σχολικής Ζωής με δικό του κωδικό (αποθηκεύεται κρυπτογραφημένος).
- Εκτυπώσεις / PDF: συνολικές, ανά μήνα, ανά κατηγορία, έλεγχος Calendar, Οδηγός, Ημερολόγιο.
- Εισαγωγή από Excel / CSV με προεπισκόπηση, διπλότυπα και λάθη ανά γραμμή.
- Εξαγωγές: CSV εφαρμογής, πίνακας ιστοσελίδας (Ninja Tables), Google Calendar CSV, ICS (σταθερά αναγνωριστικά, ζώνη ώρας Ελλάδας).
- Κατηγορίες με κανόνες εξαγωγής· οι δράσεις «Εσωτερικής Αξιολόγησης» δεν εξάγονται ποτέ σε ημερολόγια ή ιστοσελίδα.
- Δεδομένα στα Έγγραφα, αυτόματα αντίγραφα, ημερήσιο αντίγραφο σε USB/OneDrive, κοινή χρήση από πολλούς υπολογιστές με προστασία ταυτόχρονης χρήσης.
- Ενημέρωση μέσα από την εφαρμογή, με επιστροφή σε προηγούμενη έκδοση.

## Για προγραμματιστές

- `src/`: εφαρμογή (Python 3.12, μόνο βασική βιβλιοθήκη· τοπική υπηρεσία + σελίδα HTML χωρίς εξωτερικές βιβλιοθήκες).
  `core.py` βάση και κανόνες (ίδιο σχήμα SQLite με τη v1.7) · `exports.py` εισαγωγές/εξαγωγές · `reports.py` εκτυπώσεις · `storage.py` φάκελοι, κλείδωμα, αντίγραφα · `server.py` API και παράθυρο · `updater.py` ενημερώσεις · `index.html` διεπαφή · `manual.html` οδηγός.
- `tests/`: αυτόματοι έλεγχοι (`python -m unittest discover -s tests`)· `tools/smoke.py`: έλεγχος λειτουργίας.
- Τοπική εκτέλεση: `python src/server.py` (με `PDS_DATA_DIR=<φάκελος>` για δοκιμαστικά δεδομένα).
- `tools/build_package.py`: runtime x64/x86 και πακέτα· `installer/pds.iss`: Setup.exe (Inno Setup).

### Νέα έκδοση
1. Αλλάξτε το `VERSION` στο `src/core.py` και γράψτε `UPDATE_x.y.z.txt` (και στην κορυφή του `CHANGELOG.txt`).
2. Commit και push στο `main`.
3. Το GitHub ελέγχει την εφαρμογή σε Windows (64-bit και 32-bit), φτιάχνει Setup.exe, φορητό zip και αρχείο ενημέρωσης, δοκιμάζει εγκατάσταση/απεγκατάσταση και δημοσιεύει Release. Οι εγκατεστημένες εφαρμογές το βρίσκουν μόνες τους.

Στο αποθετήριο δεν αποθηκεύονται ποτέ δεδομένα σχολείου (`.gitignore`: `data/`, `*.db` κ.λπ.).
